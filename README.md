# Math Quiz Game (C++)

A console-based math quiz that generates random questions, checks the player's answers, and shows the final result.

## Features
- Random questions: addition, subtraction, multiplication, division
- Multiple difficulty levels and mixed operations
- Instant feedback with the correct answer shown on mistakes
- Final result with pass/fail

## Concepts Used
- Structs and Enums
- Functions
- Random number generation
- Loops and conditions

## How to Run
```
g++ main.cpp -o quiz
quiz.exe
```
